# PulseForm — Product Management Case Study

PulseForm is a personal product-management portfolio project exploring how a fragmented fitness experience can become a clear, motivating journey from exercise discovery to action.

This project adapts and substantially improves an existing fitness-tracker codebase. The work focuses on product strategy, UX direction, feature refinement, quality, and a complete visual redesign. It does not claim ownership of another creator's biography, achievements, partnerships, audience, or business accounts.

## Product opportunity

Fitness tools often separate exercise discovery, progress guidance, and planning into disconnected experiences. PulseForm brings those jobs together in one responsive product concept so users can discover movements, understand their BMI, and create a workout plan with less friction.

## Target users

- Beginners who need a clear starting point
- Returning exercisers looking for structured guidance
- Goal-oriented users who want exercise discovery and planning in one place

## Product goals

- Reduce the time required to find a relevant exercise
- Make health information easier to understand and act on
- Build trust through clear feedback, validation, and error states
- Create a consistent experience across desktop and mobile

## Implemented product improvements

- Reworked navigation, page hierarchy, responsive layouts, and visual theme
- Introduced the PulseForm brand direction and original interface assets
- Improved exercise discovery and API failure handling
- Added BMI validation, healthy-weight guidance, and a reset action
- Fixed authentication flows and sign-up usability
- Improved pagination behavior and theme consistency
- Added safer chatbot message rendering
- Added automated tests for important BMI and authentication flows

## Product decisions demonstrated

- Prioritization of high-friction user journeys
- Conversion of usability findings into scoped product changes
- Definition of success states, error states, and guardrails
- Responsive experience and accessibility considerations
- Validation through automated tests, production builds, and browser QA

## Suggested success metrics

- Exercise-search completion rate
- Time from landing to first useful exercise result
- Workout-plan generation completion rate
- BMI tool completion and reset rates
- Authentication completion and error rates
- Seven-day return rate

## Technology

React, JavaScript, Material UI, Firebase-ready configuration, and third-party fitness APIs.

## Run locally

1. Clone the repository.
2. Copy `.env.example` to `.env`.
3. Add your own service credentials.
4. Run `npm install`.
5. Run `npm start`.

External integrations are configured with placeholders. No inherited personal accounts, payment links, contact details, or deployment URLs are required.
